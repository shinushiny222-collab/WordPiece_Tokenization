# WordPiece_Tokenization

## Project Description

This project implements the WordPiece Tokenization algorithm from scratch using Python.

WordPiece is a subword tokenization technique commonly used in Natural Language Processing (NLP). It divides words into smaller subword tokens and uses the `##` prefix to represent continuation tokens.

This project demonstrates how WordPiece tokenization works step by step without using a pre-built tokenizer library.

## Project Workflow

The implementation follows these steps:

1. Read the raw word frequency data
2. Perform the initial WordPiece split
3. Create the initial vocabulary
4. Calculate token frequencies
5. Calculate pair frequencies
6. Calculate WordPiece scores
7. Select the best pair
8. Merge the selected pair
9. Repeat the merging process
10. Generate the final word splits
11. Generate the final vocabulary
12. Perform longest-match tokenization
13. Handle unknown words using `[UNK]`
14. Convert tokens into token IDs

## Example

For the word:

```text
robotic

The algorithm initially splits the word into individual characters:

r ##o ##b ##o ##t ##i ##c

During training, frequently occurring token pairs are merged to create larger subword tokens.

The final tokenization depends on the vocabulary learned during the training process.

WordPiece Score

The score for each adjacent token pair is calculated using:

Score = Frequency of Pair / (Frequency of First Token × Frequency of Second Token)

The pair with the highest score is selected for merging.

Unknown Token

The [UNK] token is used when a word cannot be completely tokenized using the learned vocabulary.

Example:

Input: unknownword
Output: [UNK]
